# version

Show Lynx version information.

## Synopsis

```bash
lynx version [flags]
```

## Flags

| Flag | Type | Default | Description | Example |
|------|------|---------|-------------|---------|
| `-h`, `--help` | - | - | Show help message. | `lynx version --help` |

## Examples

Show version:
```bash
lynx version
```

Example output:
```
Lynx CLI
  Version : v0.1.0
  Commit  : a1b2c3d
  Built   : 2025-01-01T12:00:00Z

Lynx Daemon
  Version : v0.1.0
  Commit  : a1b2c3d
  Built   : 2025-01-01T12:00:00Z

Protocol
  CLI     : v1
  Daemon  : v1
```
