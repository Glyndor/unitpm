# 🦁 `lynx version`

> *Show Lynx version information for the CLI, Daemon, and IPC Protocol.*

## 📖 Synopsis

```bash
lynx version [flags]
```

## Description

Show Lynx version information for the CLI, Daemon, and IPC Protocol.

## ⚙️ Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `-h`, `--help` | - | - | Show help message. |

## 🚀 Examples

Show version:
```bash
lynx version
```

## 📋 Example Output

```

  Version : v0.1.0
  Commit  : a1b2c3d
  Built   : 2025-01-01T12:00:00Z

Lynx Daemon

  Commit  : a1b2c3d
  Built   : 2025-01-01T12:00:00Z

Protocol
  CLI     : v1
  Daemon  : v1
```
