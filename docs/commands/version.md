# version

Show Lynx version information.

## Synopsis

```bash
lynx version [flags]
```

## Flags

| Flag | Type | Description |
|------|------|-------------|
| `-h`, `--help` | - | Show help message. |

## Examples

Show version:
```bash
lynx version
```

Output example:
```
Lynx CLI
  Version : 0.1.0
  Commit  : a1b2c3d
  Date    : 2025-01-01
  Protocol: v1

Lynx Daemon
  Version : 0.1.0
  Commit  : a1b2c3d
  Date    : 2025-01-01
  Protocol: v1

Protocol
  CLI : v1
  Daemon : v1
```
